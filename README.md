# Excel Sales Dashboard

An interactive Excel dashboard project created to summarize and analyze
sales data using tables, formulas, summaries, and charts.

## Project Overview

This project organizes sales records and presents key information in an
easy-to-understand dashboard. It is designed to practice Excel data
analysis, reporting, and dashboard-building skills.

## Workbook Sheets

-   **Dashboard** --- visual overview of key sales insights and charts.
-   **Sales_Data** --- source sales records used for analysis.
-   **Product_Summary** --- sales summary by product.
-   **Monthly_Summary** --- sales trends summarized by month.
-   **Region_Summary** --- sales performance summarized by region.
-   **Quantity** --- quantity-related analysis.
-   **Instructions** --- notes and guidance for using the workbook.

> Sheet names may differ slightly depending on the final workbook
> version.

## Features

-   Sales data organized in a structured worksheet
-   Product-wise, month-wise, and region-wise summaries
-   Charts for quick comparison and trend analysis
-   Dashboard layout for presenting insights clearly
-   Separate source-data and summary sheets for easier maintenance

## Tools Used

-   Microsoft Excel
-   Excel formulas, tables, summaries, and charts

## How to Use

1.  Download the Excel workbook from this repository.
2.  Open it in Microsoft Excel.
3.  Review the `Dashboard` sheet for the visual summary.
4.  Explore the summary sheets to see product, monthly, regional, and
    quantity analysis.
5.  Use the `Sales_Data` sheet to review the source records.

## Project Purpose

This project demonstrates practical Excel skills in data organization,
sales analysis, summary reporting, and dashboard design. It can be
included in a beginner data analytics portfolio.
